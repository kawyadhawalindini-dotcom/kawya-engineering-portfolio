Project 01 · Power Systems

Power System Analysis and Fault Simulation

Investigation of electrical network behaviour under normal operating conditions and symmetrical and unsymmetrical faults using PSCAD.

Software PSCAD
Domain Electrical Power Systems
Project focus Fault Analysis
01 · Overview

Project Overview

This project focuses on developing a representative electrical power network in PSCAD and analysing its behaviour under normal operating conditions and selected fault scenarios. Voltage, current and power measurements will be used to compare system performance before and during faults.

02 · Objectives

Objectives

  • Develop a power system model consisting of a source, transformer, line and electrical loads.
  • Measure bus voltages and line currents during normal operation.
  • Investigate three-phase fault behaviour.
  • Investigate line-to-ground fault behaviour.
  • Compare voltage response and fault current for the selected operating conditions.
  • Discuss the engineering implications of the simulation results.
03 · System Model

Proposed Network Configuration

The planned network includes an AC source, a transformer, a transmission or distribution line, a load bus and electrical loads. Measurement points will be placed at appropriate locations to record system behaviour.

Model status: System diagram, component parameters and PSCAD screenshots will be added after the simulation model has been implemented and verified.
04 · Methodology

Simulation Methodology

  1. Define the network configuration and component parameters.
  2. Build the electrical model in PSCAD.
  3. Run the normal operating case and record voltage, current and power measurements.
  4. Introduce a three-phase fault and record the resulting system response.
  5. Introduce a line-to-ground fault and record the resulting system response.
  6. Compare the cases using waveforms, numerical measurements and engineering analysis.
05 · Results

Simulation Results

Simulation results will be documented after the model has been executed. The analysis will include bus voltage, line current, fault current and power flow where applicable.

Results are not yet available. No simulated values or conclusions have been assumed in this section.
06 · Engineering Discussion

Analysis and Conclusion

The completed study will examine how the selected faults affect voltage, current and power transfer. The final discussion will be based on the actual PSCAD waveforms, model parameters and measured results.
