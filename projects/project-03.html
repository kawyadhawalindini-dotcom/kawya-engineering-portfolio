PROJECT 03 · POWER SYSTEMS

Renewable Energy Grid Integration

Investigating the interaction between renewable energy sources and the electrical grid, including voltage response, power flow and fault behaviour using PSCAD.

Back to Projects

01 / OVERVIEW

Project Overview

This project aims to model a grid-connected renewable energy system and investigate how renewable generation affects power flow and network performance. PSCAD simulations will be used to examine operating conditions and selected electrical faults.

02 / OBJECTIVES

Project Objectives

Renewable Integration

Represent renewable generation connected to an electrical network at the point of common coupling.

Power Flow

Investigate power transfer between the renewable source, grid and connected load.

Network Response

Examine voltage and current behaviour under selected operating conditions.

Fault Analysis

Study selected fault conditions and compare the resulting electrical responses.

03 / SYSTEM MODEL

Proposed System Configuration

The final configuration will reflect the implemented PSCAD model. The planned network may include:

Grid Source

Represents the external electrical supply and its network conditions.

Renewable Generator

Represents a renewable source, such as a PV system, connected to the grid.

Transformer and Line

Represent the relevant voltage interface and transmission path.

Point of Common Coupling

Provides a location to investigate voltage, current and power exchange.

04 / METHODOLOGY

Simulation Methodology

  1. Develop the grid and renewable-source model in PSCAD.
  2. Define network parameters and measurement points.
  3. Run the model under normal operating conditions.
  4. Vary renewable generation or penetration levels where supported by the model.
  5. Apply selected fault scenarios, such as three-phase and line-to-ground faults.
  6. Record and compare voltage, current and power responses.

05 / RESULTS

Simulation Results

Results and plots will be added after the PSCAD model has been implemented and tested. No numerical performance results are claimed at this stage.

Planned Analysis

  • Grid and renewable power contribution.
  • Voltage and current response during normal operation.
  • Network response to selected fault conditions.
  • Comparison of operating scenarios using simulation data.
